## Pizzeria Mamma Mia con React + Vite

Proyecto Estatico, creado con React + Vite, para una pizzeria, Hito 2 actualizado

## Acceso

https://github.com/buffonico/hito-2-Pizzaria-Mamma-Mia
https://buffonico.github.io/hito-2-Pizzaria-Mamma-Mia/


## Descripción

    En esta oportunidad a nuestra pagina de pizzeria, se le agrego el Login y un Registro, que nos permite entrar mas seguro con nuestros datos al momento de se llene el carritos con su total.

    
  

## Tecnologías Utilizadas

- HTML5
- CSS3
- JS
- React + Vite
